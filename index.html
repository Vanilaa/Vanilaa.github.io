Projects

Hetero MRTA with Priority Rewards

This project extends a reinforcement learning framework for heterogeneous multi-robot task allocation by integrating task priority directly into the reward function. By modifying the objective to penalize delays on high-priority tasks, the system trains agents to complete urgent tasks first, while maintaining efficient decentralized coordination. Simulation results demonstrate the method effectively handles large-scale scenarios with up to 150 agents and 500 tasks.

Greenhouse Gas Flux Chamber

The greenhouse gas (GHG) flux chamber is a low-cost and portable system designed to measure methane and carbon dioxide fluxes on water bodies. It integrates onboard electronics, gas sensors, and supporting hardware into a floating chamber that could float on water for days to weeks to collect data. The project includes open-source code and schematics to support sensor communication and data acquisition, and full documentation to support a wide range of users.

Pi Looper

Pi-Looper is a compact loop station built on the Raspberry Pi Pico that lets musicians record, layer, and replay instrument tracks in real time. By integrating FRAM for persistent storage and a custom amplifier plus FSM-based control logic, Pi-Looper enables flexible saving, retrieval, and seamless looping of guitar audio beyond traditional loop stations.

Autonomous Maze Robot

This an autonomous maze-navigating robot capable of exploring unknown environments, detecting IR “treasure” beacons, and communicating data back to a base station without any human intervention. To achieve this, the robot is equipped with sensors to carry out RF communication, FFT-based frequency detection, and PID-controlled path following.

Smart Dashboard

The Smart Dashboard project created an interactive desktop gadget that integrates multiple real-time functions—such as weather display, Spotify playback control, and an on-device drawing game—using a Raspberry Pi with a TFT screen and LED panel. It fetches external data like real weather via APIs and Spotify metadata, displays animated visuals, and supports user interactions.

Intelli Flow

Intelli Flow is a smart traffic light system that dynamically adjusts traffic signal timing based on real-time flow data input (e.g., from a joystick) and displays current traffic conditions on an OLED screen. By optimizing light durations in response to measured traffic, the system aims to reduce vehicle waiting time and associated emissions as part of a “Green Data” themed makeathon project.
